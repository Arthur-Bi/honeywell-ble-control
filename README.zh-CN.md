# 霍尼韦尔蓝牙灯控：公开框架

简体中文 · [English](README.md)

适用于霍尼韦尔 **HWX-SICS-07（学习版）** 场景智能光控器的本地网页与
ESP32-C3 固件框架。面板标签注明 **BLE／LeMesh**，使用两颗 CR3032 电池。
测试灯具的商品名称为霍尼韦尔 **02BPlus** 吸顶灯；其他灯具、面板版本及固件
尚未确认兼容。本项目为独立研究，与霍尼韦尔官方无关联。

仓库仅包含面板正面照片，图片文件元数据已清除。

## 公开范围与私有部分

本仓库提供：

- 原先的简单中文网页：场景、收藏调用、关灯、手动按住、指定时长模拟长按，
  以及有输入边界的绝对亮度／色温实验。
- 仅监听本机回环地址的 Python HTTP 服务与 USB 串口桥。
- 基于 ESP-IDF 5.4.2／ESP32-C3 的 NimBLE 扫描、广播通用框架。
- 下文所列的指令码、场景及有语义的参数映射。
- 只读抓包与候选控制器标识提取工具。

**仓库不包含可以直接使用的完整蓝牙控灯报文编码器。** 真实设备身份、
绑定／认证材料、完整原始广播、抓包样本、负载转换与校验算法、
原有私有编码实现均未公开。默认适配层始终拒绝发包。

公开固件可以编译并被动采集广播；网页支持不连接硬件的演示。
**实际控灯必须自行补充本地私有适配层。** 仅获得候选控制器标识，
并不意味着已经具备完整可用的发送配置。

## 工作原理

~~~text
浏览器 → 电脑上的 Python 服务 → USB 串口 → ESP32-C3
                                           ↓
                                语义请求＋独立自增序号
                                           ↓
                                    本地私有适配层
                                           ↓
                                    BLE 广播 → 灯具
~~~

这里的“服务器”运行在连接 C3 的电脑上。现有网页方案需要电脑持续运行。
独立 Wi-Fi、MQTT、HA 自动发现、红外输入和米家模组 GPIO 输入，目前都属于
后续接入思路，并非本仓库已经实现的功能。

## 指令码与参数语义

下面列的是**操作语义，不是完整蓝牙帧**。表中只列有意义的参数；完整广播所需的
填充、身份、认证及封装由使用者自己的私有适配层提供。

| 功能 | 指令码 | 有语义的参数 | 串口命令 |
| --- | --- | --- | --- |
| 关灯 | 0x01 | 无语义参数 | off |
| 休息模式 | 0x0E | 场景 0；模式选择值 1 | scene 0 |
| 作业模式 | 0x0E | 场景 1；模式选择值 1 | scene 1 |
| 网课模式 | 0x0E | 场景 2；模式选择值 1 | scene 2 |
| 早餐唤醒 | 0x0E | 场景 3；模式选择值 1 | scene 3 |
| 舒缓助眠 | 0x0E | 场景 4；模式选择值 1 | scene 4 |
| 伴读夜灯 | 0x0E | 场景 5；模式选择值 1 | scene 5 |
| 调用“我的最爱” | 0x0E | 场景 128（0x80）；模式选择值 1 | scene 128 |
| 亮度按下／松开 | 0x28 | 1＝按下，2＝松开 | brightness_press / brightness_release |
| 色温按下／松开 | 0x46 | 1＝按下，2＝松开 | temperature_press / temperature_release |
| 绝对亮度候选 | 0x08 | 原始值的高、低字节 | abs_b RAW LAYOUT |
| 绝对色温候选 | 0x0D | 两个相对通道参数 | abs_t POSITION LAYOUT |

串口 **on** 是进入作业模式的别名，不代表已验证独立的通用开灯指令。
“我的最爱”仅执行调用，不会保存或覆盖收藏。长按保存收藏、
灯具原生多收藏槽位均未实现，也没有确认额外收藏槽位存在。

### 绝对值的含义与边界

- 网页亮度候选值范围为 5–60，乘十后映射为原始值 50–600；
  两个语义字节分别为 raw / 256 和 raw % 256。
- 色温候选位置限制为 25–75。位置 25／50／75 对应的通道参数分别为
  (128, 64)／(128, 128)／(64, 128)。
- p <= 50 时参数为 (128, round(256*p/100))；
  p > 50 时为 (round(256*(100-p)/100), 128)。
- 方案 A 使用七个线协议参数位置，方案 B 使用两个。
  私有适配层处理完整布局，公开请求只携带有效参数。
  两种布局在测试灯具上都产生了实际响应。

已观察到：亮度候选值 20 比 10 亮；色温位置 25 比 75 冷。
这些值**尚未标定为实际亮度百分比或 Kelvin**。
输入边界是本项目的实验限制，并非厂商公布的极限。
不同起始状态及其他灯具仍需自行验证。

### 自增序号与重复广播

每条新的逻辑指令使用一个新的 8 位序号，255 后回到 0。
同一条指令重复广播时，序号保持不变。发送端序号保存在 NVS 中；
观察到原装面板自己的序号后，不会倒退已经初始化的发送端序号。

广播配置间隔为 20ms，每条指令持续约 300ms，另有控制器超时限制。
300ms 窗口接近实测原面板的广播持续时长；**20ms 是本项目的配置值，
不能视为已经精确测得的原面板空口间隔。**
发送成功也不等于收到灯具执行回执。
